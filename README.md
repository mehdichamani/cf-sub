# 🌐 Cloudflare Subscription Provider & Local Xray Tester (`cf-sub`)

یک پروژه سبک، مینیمال و دو‌منظوره برای:
1. **میزبانی فایل‌های `.txt` و `.json` به عنوان سابسکریپشن کلاینت‌های V2Ray، Sing-box، Hiddify و... روی کلودفلر ورکر.**
2. **رابط کاربری وب محلی (Local Web GUI) برای تست سلامت کانفیگ‌ها با هسته Xray، حذف نودهای سوخته و مرتب‌سازی بر اساس پینگ (به صورت مستقیم یا زنجیره‌ای Chain).**

---

## 🌟 قابلیت‌های اصلی

### ۱. میزبانی سابسکریپشن (Cloudflare Worker)
- **پشتیبانی مستقیم از `.txt` و `.json`**:
  - فایل‌های `.txt` حاوی لینک‌های پروتکل‌های `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://`
  - فایل‌های `.json` کانفیگ کامل نرم‌افزارهای **Sing-box** و **Xray/Hiddify**
- **داشبورد تحت وب فارسی**: با ورود به ریشه دامنه و وارد کردن Secret، تمام پروفایل‌ها، لینک‌های مستقیم سابسکریپشن و QR Code نمایش داده می‌شوند.
- **ایمپورت مستقیم در کلاینت‌ها**:
  - در **Sing-box** و **Hiddify**: قرار دادن لینک مستقیم فایل `.json` به صورت Remote Profile.
  - در **v2rayNG** و **v2rayN**: ایمپورت لینک معمولی سابسکریپشن (Base64 یا Raw).
- **امنیت بالا با Secret**: عدم امکان اسکن یا دسترسی غیرمجاز (ارسال پاسخ 404 در صورت عدم ارائه Secret).

### ۲. تستر و پالایشگر محلی کانفیگ‌ها (Local Web GUI)
- رابط کاربری زیبا و تحت وب در مرورگر (`http://localhost:3000`)
- استفاده مستقیم از هسته محلی Xray برای سنجش واقعی اتصال به اینترنت
- **دو حالت تست**:
  - **مستقیم (Direct)**: تست پینگ و اتصال مستقیم به سرورها
  - **زنجیره‌ای (Chain Proxy)**: تست با اتصال از طریق پروکسی محلی (Landing Proxy مانند `socks5://127.0.0.1:10808`)
- **حذف خودکار کانفیگ‌های ناسالم**: جداسازی سرورهای سوخته، مرتب‌سازی نودهای سالم از کمترین پینگ و ذخیره خودکار فایل پاک‌سازی شده در پوشه `profiles/`.
- امکان کپی فوری یا دانلود فایل خروجی تمیز.

## 📁 ساختار پروژه

```text
cf-sub/
├── profiles/            # پوشه قرارگیری فایل‌های کانفیگ (.txt و .json)
├── tools/
│   ├── gui-server.ts    # سرور رابط وب تستر محلی با Xray
│   ├── tester.ts        # هسته تست و ارزیابی پینگ با Xray
│   ├── geo.ts           # تشخیص موقعیت جغرافیایی و پرچم کشور
│   ├── xray-converter.ts# تبدیل لینک‌های URI به Outbound در Xray
│   └── generate-profiles.ts # اینلاین‌سازی خودکار کانفیگ‌ها در ورکر
├── src/
│   ├── index.ts         # نقطه ورود ورکر کلودفلر و احراز هویت
│   ├── nodes.ts         # پارسر و فرمت‌کننده سابسکریپشن
│   ├── ui.ts            # قالب داشبورد وب ورکر
│   └── types.ts         # تایپ‌های تایپ‌اسکریپت
├── launch.sh            # منوی مدیریت سریع و لانچر پروژه
└── wrangler.jsonc       # تنظیمات Cloudflare Workers
```

## 🚀 راهنمای سریع و دستورات

می‌توانید تمام عملیات پروژه را هم از طریق منوی تعاملی لانچر (`./launch.sh`) و هم به صورت **دستورات مستقیم CLI** اجرا کنید:

### ۱. اجرای منوی تعاملی لانچر
```bash
./launch.sh
```

---

### ۲. دستورات ساده و مستقیم لانچر (CLI)

| عملیات | دستور با لانچر | معادل با pnpm | توضیح |
| :--- | :--- | :--- | :--- |
| **تستر و پنل وب محلی** | `./launch.sh gui` | `pnpm run gui` | اجرای وب‌سرور محلی روی پورت ۳۰۰۰ جهت تست نودها با Xray و پاک‌سازی |
| **انتشار روی کلودفلر** | `./launch.sh deploy` | `pnpm run deploy` | بیلد خودکار پروفایل‌ها و دیپلوی مستقیم روی ورکر کلودفلر |
| **تنظیم سکرت در کلودفلر** | `./launch.sh secret` | `pnpm run secret:put` | ست کردن `SUB_SECRET` روی کلودفلر ورکر و همگام‌سازی آن با `.env` |
| **بررسی وضعیت اکانت** | `./launch.sh whoami` | `pnpm exec wrangler whoami` | تست اتصال، نمایش ایمیل و اکانت‌های متصل به کلودفلر |

---

### ۳. سایر دستورات پرکاربرد توسعه محلی

- **تست و ران محلی ورکر (Development Server):**
  ```bash
  pnpm run dev
  ```
  *(ورکر با تنظیمات `.env` روی پورت ۸۷۸۷ محلی اجرا می‌شود)*

- **پالایش و تست دسته‌ای کانفیگ‌ها در ترمینال (بدون پنل وب):**
  ```bash
  pnpm run curate         # تست مستقیم پینگ نودها
  pnpm run curate:chain   # تست زنجیره‌ای از طریق ساکس محلی
  ```

- **بررسی صحت تایپ‌ها (Typecheck):**
  ```bash
  pnpm run typecheck
  ```
